# Bro Men Salon — Static Website

Responsive static website concept for **Bro Men Salon, Bettamakki, Thirthahalli** built with React + Vite.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL shown by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```
The production website is generated in the `dist/` directory.

## Before publishing
- Confirm and update the sample service prices in `src/App.jsx`.
- Add the salon's real phone number and opening hours.
- Confirm the exact Google Maps location.
- Gallery and hero photos are loaded from Unsplash and require an internet connection.

## Current scope
Frontend only. No backend, database, real booking system, or WhatsApp number is configured yet. Java Spring Boot + MySQL can be integrated in a later phase.
