# Bro Men Salon

A modern and responsive website for Bro Men Salon, designed to showcase salon services and provide customers with an easy way to explore the business.

## 🌐 Live Website

**[Visit Bro Men Salon](https://salon-website-five-indol.vercel.app/)**

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- Lucide React

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/SKANDAMV27/Salon-Website.git
   ```

2. Navigate to the project:

   ```bash
   cd Salon-Website/bro-men-salon
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```

## 📦 Deployment

The website is deployed on Vercel.
